# TelePlan-Studio-RF-OFC-GIS-Feasibility-Engine-
TelePlan Studio is a browser-based, client-side Geographic Information System (GIS) and Computer-Aided Design (CAD) platform designed for internet service providers (ISPs),It enables planning, route feasibility analysis, link budget and calculation for both Wireless Radio Frequency (RF) links and Optical Fiber Cable (OFC / FTTH) networks.

Core Functional ModulesA. Radio Frequency (RF) Feasibility EngineFirst Fresnel Zone Radius ($F_1$):
Calculates the maximum radius of clearance needed at any point along the path:$$F_1 = 17.32 \times \sqrt{\frac{d_1 \times d_2}{f \times D}}$$(Where $d_1, d_2$ are distances from endpoints in km, $D$ is total distance in km, and $f$ is frequency in GHz).Free Space Path Loss (FSPL):$$FSPL\text{ (dB)} = 20\log_{10}(d) + 20\log_{10}(f) + 92.45$$Link Budget & Expected RSSI:$$P_{rx} = P_{tx} + G_{tx} + G_{rx} - FSPL - L_{misc}$$Terrain & Clearance Profile: Evaluates whether direct LoS has the mandatory 60% first Fresnel zone clearance above ground obstruction levels.B. Optical Fiber Cable (OFC) & FTTH ModuleCable Standards Supported: 2F (Drop), 6F (Sub-feeder), 12F, 24F, 48F, and 96F.TIA-598-A Color Code Matrix: Built-in standard optical fiber identification color mapping (Blue, Orange, Green, Brown, Slate, White, etc.) rendered inside inspection popups for splice engineers.PON Optical Attenuation Budget:Fiber attenuation calculation based on wavelength ($0.35\text{ dB/km}$ at $1310\text{nm}$, $0.22\text{ dB/km}$ at $1550\text{nm}$).Passive optical splitter insertion losses ($1:4 \approx 7.2\text{ dB}$, $1:8 \approx 10.5\text{ dB}$, $1:16 \approx 13.8\text{ dB}$, $1:32 \approx 17.1\text{ dB}$).Verification of subscriber drop distance ($< 250\text{m}$ target from nearest FAT).C. Role-Based Access Control (RBAC) & DatabaseGuest / Field Viewer Mode: Read-only access to inspect paths and drop test CPEs without altering master backbone network data.Admin Mode: Authenticated access allowing placement, coordinate dragging, parameter updates, renaming, and database record deletions.Storage Schema:telecom_nodes: Stores id, name, type (NOC, OLT, AP, FAT, Joint, CPE), lat, lng, and hardware attributes.telecom_cables: Stores polyline coordinate arrays, core count, cable category, and measured lengths.telecom_surveys: Stores GPS geo-tagged field observations with surveyor metadata.3.
